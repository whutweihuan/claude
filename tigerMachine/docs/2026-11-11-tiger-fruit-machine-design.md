# 复古老虎水果机 · 设计文档

日期：2026-11-11
状态：待确认

## 1. 背景与意图

做一个能在本地直接打开的复古街机水果机，还原 90 年代游戏厅里那台机器的核心体验：24 格跑灯、押分、开火车、大三元 / 小三元、天门、猜大小、爆机音效。重点是"那味儿"——霓虹灯、LED 数字、机械跑灯声、投币声，以及听到"开火车啦"时的兴奋感。

这是纯娱乐的虚拟币游戏，不联网、不涉及真实货币、不保存赌资。

## 2. 目标

- 双击 `index.html`（或 `run_tiger.bat`）即可在 Windows 浏览器里玩，不需要安装依赖、不需要起服务器。
- 完整的押分 → 跑灯 → 开奖 → 猜大小循环，手感干脆。
- 至少包含以下彩头：**开火车、小三元、大三元、天门**，并带对应的语音 / 音效 / 动画。
- 复古街机视觉：深色机箱、霓虹描边、LED 跑马灯、CRT 扫描线、像素风水果图标。
- 游戏逻辑与界面分离，逻辑可用 Node 单独跑测试。

## 3. 非目标

- 不做真实赌博、充值、提现、联网对战、排行榜。
- 不追求 1:1 复刻某一台 ROM 的灯位或概率，只做"神似"的致敬版。
- 不做账号、存档、长期养成。每次打开从 1000 虚拟币开始。
- 不做移动端专属交互；桌面浏览器优先，窗口缩小能等比适配即可。

## 4. 反目标（做得再顺也不该出现）

- 玩家输光后无事可做：必须始终能点"投币"补充虚拟币。
- 必须联网或依赖外部图片 / 字体：所有图案用 Canvas 画，音效用 WebAudio 合成。
- 诱导真实赌博的文案或功能：界面固定标注"纯娱乐 · 虚拟币"。

## 5. 平台与文件结构

技术栈：原生 HTML + CSS + JavaScript（ES2018+），Canvas 2D 渲染，WebAudio 合成音效，Web Speech API 可选语音。

```
tigerMachine/
  index.html        # 页面骨架、Canvas、控制面板 DOM
  style.css         # 机箱、面板、CRT、霓虹样式
  engine.js         # 纯逻辑：押注、开奖、彩头、猜大小（浏览器/Node 通用）
  render.js         # Canvas 绘制：机箱盘面、灯位、水果、天门
  audio.js          # WebAudio 音效与语音
  game.js           # 控制器：DOM、动画状态机、输入、自动模式
  test_engine.js    # node test_engine.js
  run_tiger.bat     # 双击打开 index.html
  README.md         # 运行方式、玩法、赔率表
  docs/2026-11-11-tiger-fruit-machine-design.md
```

所有相关文件（代码、文档、启动脚本）都放在 `tigerMachine/` 下，不散落到仓库其他目录。

说明：设计初稿提过"单文件 HTML"，为了能对核心逻辑做自动化测试，拆成 `engine.js` + `game.js`。仍然是纯本地静态文件，双击 `index.html` 就能玩，不需要服务器。

## 6. 盘面与图案

24 个灯位绕成一圈（圆形跑道），中间是"天门"大奖区。

9 个可押图案 + LUCK 空门：

| 图案 | 赔率 | 环上灯数 | 实际出现概率 |
| --- | ---: | ---: | ---: |
| 小香蕉 | 4× | 5 | 20.00% |
| 小芒果 | 6× | 3 | 13.33% |
| 苹果 | 8× | 3 | 10.00% |
| 香蕉 | 12× | 2 | 6.67% |
| 芒果 | 15× | 1 | 5.33% |
| 西瓜 | 20× | 1 | 4.00% |
| 双星 | 30× | 1 | 2.67% |
| 双七 | 40× | 1 | 2.00% |
| BAR | 50× | 1 | 1.60% |
| LUCK / 跑空 | — | 6 | 31.40% |
| 彩头触发 | — | — | 3.00% |

概率与灯数不必严格对应；跑灯最终停在哪一格由引擎按权重决定，视觉上仍然绕环运行。

九个图案的出现概率按 `0.80 / 赔率` 分配，合计 **65.6%**；LUCK / 跑空 **31.4%**；彩头 **3%**，三者合计 100%。这样每个图案单独押 1 分时的期望返还都是 0.80，九门均注基础 RTP 也是 0.80；彩头再加约 0.145，触发保底后的总 RTP 约 0.97。

押中图案时按"该图案押分 × 赔率"赔付；跑空不赔。

## 7. 核心玩法

### 7.1 押分

- 9 个图案各有一个押分格，范围 0–99，步进由快捷筹码（1 / 5 / 10 / 50）决定。
- 面板显示每个图案的当前押分、总押分、当前金币。
- "全清"清空所有押分；"全押"按当前筹码给每个图案加一份（金币不足时只加到能负担为止）。
- 开始一局时立即扣除总押分；总押分为 0 或金币不足时不能开始。
- "投币"按钮每次 +100 虚拟币，随时可用，保证不会卡死。

### 7.2 跑灯开奖

1. 扣除总押分。
2. 引擎按权重决定结果：普通图案 / LUCK / 彩头。
3. 跑灯从当前位置绕环若干圈，减速停在目标灯位。
4. 若停在押过的图案：赢得 `该图案押分 × 赔率`。
5. 若停在没押的图案或 LUCK：本局无奖。
6. 中奖后进入"猜大小"环节（含彩头；可放弃直接收分）。
7. 彩头结果替代本局普通开奖，不额外叠加普通图案赔付。

### 7.3 猜大小

- 任意中奖（含彩头）后都可以选择猜大小；不猜就直接收分。
- 弹出选择：**小（1–6）** / **大（8–13）**。
- 系统随机开 1–13；7 为"和"，庄家通吃。
- 猜对：本局奖金翻倍；猜错：本局奖金清零。
- 最多连续猜 3 次，之后自动收分；也可以随时点"收分"落袋。
- 自动模式不猜大小，直接收分。

### 7.4 彩头

彩头总触发率 3%，按以下权重抽取：

| 彩头 | 占彩头比例 | 每局绝对概率 | 玩法 | 期望赔付（九门均注时） |
| --- | ---: | ---: | --- | ---: |
| 小三元 | 40% | 1.2% | 小香蕉、小芒果、苹果三灯同时亮，押中的按原赔率各赔一次 | 2× 总押分 |
| 大三元 | 16.67% | 0.5% | 西瓜、双星、双七三灯同时亮，押中的按原赔率各赔一次 | 10× 总押分 |
| 开火车 | 30% | 0.9% | 5 节车厢依次停灯，每节按停到的图案赔一次 | 约 4× 总押分 |
| 天门 | 13.33% | 0.4% | 中央天门转盘：小天门 5×、天门 10×、大天门 50× 总押分 | 约 8.75× 总押分 |

- 小三元 / 大三元只赔"亮起的这三个图案"上押过的分；没押的图案不赔。
- 开火车每节车厢按主盘实际权重抽取：约 65.6% 停在某个图案，34.4% 是空车；停在图案上且押过才赔，空车不赔。五节合计期望约 4× 总押分（九门均注时），可能连续爆分。
- 天门按**总押分**赔付，与具体押在哪个图案无关；转盘权重：小天门 65%、天门 30%、大天门 5%。
- 彩头保底：连续 60 局没有彩头时，下一局强制触发一个随机彩头。
- 彩头动画期间显示对应大字和语音："小三元！""大三元！""开火车啦！""天门！"

### 7.5 爆机

- 金币达到 99999 时触发"爆机"庆祝（彩带、金币雨、音效），金币不重置，继续玩。
- 仅作为彩蛋，不影响概率。

## 8. 界面布局

整体 1280×800 的机箱，等比缩放适配窗口。

- **顶部跑马灯**：霓虹标题"老虎水果机"，两侧走马灯，固定小字"纯娱乐 · 虚拟币"。
- **左侧盘面（680×680 Canvas）**：
  - 24 个 LED 灯位围成圆环，灯位里画水果图标、名称、赔率。
  - 当前跑灯高亮，中奖灯位金色闪烁。
  - 中央天门区：大门图案 + "天门" 字样 + 小天门 / 天门 / 大天门标记；彩头时大门打开、内圈跑灯。
  - 盘面下方一行状态字："开火车啦！" / "大三元！" / "差一点！"。
- **右侧控制面板**：
  - 四块 LED 数字：金币、总押分、本局奖金、彩头进度。
  - 筹码选择：1 / 5 / 10 / 50。
  - 9 行押注条目：图标、名称、赔率、押分、− / + 按钮。
  - 大按钮：投币、全清、全押、开始（红色）、自动、规则、音效开关。
  - 底部快捷键提示：空格开始、C 投币、X 全清、M 静音。
- **猜大小浮层**：中奖后覆盖在盘面中央，两个大按钮"小 1–6" / "大 8–13"，以及"收分"。
- **规则浮层**：赔率表 + 彩头说明 + 纯娱乐声明。
- **CRT 覆盖层**：扫描线、暗角、轻微闪烁。

## 9. 视觉与音效

### 9.1 视觉

- 配色：机箱深棕 / 黑（#120b08、#2a1a10），霓虹金（#ffc857）、红（#ff4d3d）、青（#4de1ff）、绿（#58e06a）。
- 水果图案用 Canvas 矢量绘制，不依赖 emoji 或外部图片；"小香蕉 / 小芒果"画成缩小版并带"小"字角标。
- LED 数字使用等宽字体 + 发光 text-shadow；中文用微软雅黑 / 黑体。
- 灯位：深色圆角方块 + 彩色描边；点亮时放大、发光、加内阴影。
- 动画统一用 `requestAnimationFrame`，支持 `?fast=1` 加速（开发调试用）。

### 9.2 音效（WebAudio 合成，无外部文件）

- 投币：两声高频"叮"。
- 跑灯：短促方波 tick，越接近停止音调越高。
- 中奖：上行琶音。
- 跑空：下行短音。
- 开火车：汽笛 + 节奏声。
- 大三元 / 天门：号角式和弦、金币雨声。
- 语音：Web Speech API 朗读"开火车啦""大三元""小三元""天门"；不可用时静默降级，不影响游戏。
- 首次点击页面后恢复 AudioContext（浏览器自动播放限制）。
- M 键 / 按钮静音，同时取消语音。

## 10. 技术设计

### 10.1 逻辑引擎 `engine.js`

不依赖 DOM，浏览器挂到 `window.TigerEngine`，Node 用 `module.exports`。核心 API：

```js
createGame({ coins = 1000, rng = Math.random })
game.bet(symbolId, delta)        // 增减押分，返回 {ok, error?}
game.clearBets()
game.betAll(unit)
game.spin()                      // 扣分并返回 SpinResult
game.collect()                   // 收分
game.guess('small'|'big')        // 猜大小，返回结果
game.insertCoin(amount = 100)
game.getState()                  // 只读快照
```

`SpinResult`：

```js
{
  kind: 'symbol' | 'luck' | 'feature',
  stopIndex: 0..23,
  symbolId: string | null,
  feature: null | { type, symbols?, carriages?, wheel?, multiplier? },
  win: number,
  pendingWin: number,
  message: string
}
```

- 引擎内维护 `coins`、`bets`、`pendingWin`、`spinsSinceFeature`、`guessCount`。
- RNG 可注入，测试用固定种子。
- 所有数值校验（押分上限、金币不足、猜大小次数）都在引擎里，界面只负责展示。

### 10.2 渲染 `game.js`

- Canvas 680×680，按 devicePixelRatio 缩放，窗口 resize 时重绘。
- 环上 24 个灯位按角度计算坐标：`angle = -Math.PI/2 + i * 2π/24`。
- 跑灯动画：先算目标格，至少跑 2 圈，用 ease-out 控制每步间隔，从 40ms 渐增到 220ms。
- 彩头动画各自独立：小 / 大三元闪烁三灯，开火车画小火车 + 5 节车厢依次停靠，天门开大门 + 内圈转盘。
- 粒子系统：金币、彩带，数量控制在几百个以内，动画结束清空。
- DOM 控制面板与引擎状态单向同步：每次操作后调用 `renderUI()`。
- 调试模式 `?debug=1`：键盘 F1–F4 强制触发四种彩头，F5 加 1000 币；`?fast=1` 动画加速。

### 10.3 交互

- 所有按钮点击有按压反馈和 click 音。
- 空格 = 开始；C = 投币；X = 全清；M = 静音。
- 动画期间禁用开始按钮；自动模式在上一局完全结束（含动画、收分、语音）后等待 1.2 秒再开下一局，不压缩动画；金币不足或手动停止时退出。开发调试可用 `?fast=1` 加速动画。
- 猜大小浮层出现时，开始按钮禁用，必须先猜或收分。

## 11. 测试与验收

### 11.1 自动化测试 `test_engine.js`

用 Node 内置 `assert`，不引入依赖。至少覆盖：

1. 初始金币 1000，押分上下限、金币不足时不能加注。
2. 开局扣总押分；押中图案按 `押分 × 赔率` 赔付。
3. 押多个图案时只有停到的那个赔。
4. 小三元只赔小香蕉 / 小芒果 / 苹果；大三元只赔西瓜 / 双星 / 双七。
5. 开火车返回 5 节车厢结果，逐节赔付。
6. 天门按总押分 × 转盘倍数赔付。
7. 猜大小：猜对翻倍、猜错清零、开 7 通杀、最多 3 次。
8. 彩头保底：连续 60 局无彩头后必定触发。
9. 环上 24 格，9 个图案都出现。
10. 10 万局蒙特卡洛：九门均注时 RTP 落在 0.85–1.05；彩头出现率落在合理区间。

运行：`cd tigerMachine && node test_engine.js`。

### 11.2 手动验收

- 双击 `run_tiger.bat` 或 `index.html`，浏览器打开，无控制台报错。
- 投币、加注、开始、跑灯、停灯、赔付数字正确。
- 四种彩头动画和语音都能触发（用调试快捷键逐一验证）。
- 猜大小可猜、可收分、3 次后自动收。
- 静音后无声音；刷新后回到 1000 币。
- 窗口缩小到 1024×640 仍完整显示，不裁切文字。

## 12. 已定的决定

- 虚拟币，无真实货币、无联网、无存档。
- 单机静态页面，双击运行，不起服务器。
- 逻辑与渲染分离，核心逻辑可用 Node 测试。
- 采用"实际概率加权 + 视觉 24 灯位"的模型，赔率用经典数值（BAR 50×），不追求灯数与概率一一对应。
- 彩头按总押分 / 押中图案赔付，不额外收门票。
- 中文界面，复古街机风。
