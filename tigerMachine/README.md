# 开火车啦 · 老虎水果机

一个复古老虎水果机：24 格跑灯、押分、猜大小，以及开火车、大三元 / 小三元、天门四种彩头。纯娱乐 · 虚拟币，不联网。

## 运行

双击 `run_tiger.bat`，或者直接用浏览器打开 `index.html`。

不需要安装依赖，不需要起服务器。

## 玩法

1. 点“投币 +100”补充虚拟币，初始 1000。
2. 选筹码（1 / 5 / 10 / 50），给九个图案加注。单门最多 99 分。
3. 点“开始”跑灯。灯停在押过的图案，按“押分 × 赔率”赔付；停在没押的图案或跑空不赔。
4. 中奖后可以猜大小：小 = 1–6，大 = 8–13，开 7 通杀。猜对翻倍、猜错清零，最多 3 次，也可以直接收分。
5. 连续 60 局没有彩头，下一局必出彩头。金币达到 99999 会爆机庆祝，金币不重置。

## 调试参数

在 `index.html` 后面加查询参数：

- `?debug=1`：暴露 `window.__tiger`，便于在控制台查看状态。
- `?fast=1`：动画加速，方便截图和调试。
- `?demo=spin`：自动投币、九门各押 1 分并跑一局。
- `?demo=smallThree` / `bigThree` / `train` / `gate`：强制触发对应彩头。
- `?demo=guess`：制造一次中奖并弹出猜大小。
- `?demo=jackpot`：把金币推到 99999 并触发爆机。
- `?demo=doubleStart`：连续调用两次开始，验证防重入（状态条应显示 `spins=1`）。

例如：

```text
index.html?debug=1&demo=train&fast=1
```

- `game.js`：控制器、动画状态机、输入
- `test_engine.js`：逻辑测试
- `docs/`：设计文档与实现计划
