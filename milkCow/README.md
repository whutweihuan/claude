# 奶牛牧场

一个挂在电脑旁边、偶尔瞄一眼的奶牛养成桌面小游戏：小牛按真实时间长大，成年牛自动怀孕生小牛，点牛挤奶卖钱，再用加工器把牛奶变成奶酪，赚得更多。

## 运行

双击 `run_milkcow.bat`，或在当前目录运行：

```bash
python cow_gui.py
```

需要 Python 3.8+（仅使用标准库和 Tkinter）。

## 玩法

- 开局 200 金币 + 一头成年牛（牧场 4 个位置）。这头牛开局就会自动怀孕，约 1 小时后生下第一头小牛。
- 成长阶段：牛仔（45 分钟）→ 青年牛（累计 135 分钟）→ 成年牛。关掉程序也照常生长。
- 成年牛 20 分钟蓄满一奶：点牛挤奶，或用“一键挤奶”一次收完。不挤不会有任何损失。
- 繁殖全自动：成年牛在牧场“牛数 + 孕妇数 < 容量”时自动怀孕（孕期 1 小时，产后休养 30 分钟）。满员时排队，卖出腾位后按排队先后补位。
- 高级饲料：每喂一份，该牛总生长时间缩短 15 分钟；每头最多 3 次，两次间隔至少 10 分钟。成年后不能喂，不喂也不会退化。
- 奶酪加工：加工器每台一次投 3 牛奶，20 分钟后自动产出 1 奶酪进仓库，机器随即空闲。
- 奶牛会在草地上自动溜达（纯观赏，不影响任何数值）。

## 存档

存档在 `milkCow/save.json`，每次操作和每 10 秒自动保存；关闭窗口时也会保存。

- 存档损坏：备份为 `save.corrupt-<时间戳>.json` 并开始新的一局。
- 存档被占用/读不到：本次运行不写盘、不覆盖原文件，状态栏提示原因。
