# 奶牛牧场（桌面挂机养成游戏）设计

日期：2026-11-12  
目标平台：Windows 10/11  
形态：本地桌面程序（Python 3.8 + Tkinter），双击即玩  
项目目录：`milkCow/`

## 1. 意图与原因

用户想要一个挂在电脑旁边的奶牛养成小游戏，风格与仓库里的 `farmer/`（小菜园）一致：主打挂机休闲，偶尔瞄一眼，过一会儿回来有东西可收。

核心乐趣链条：

- 小牛在草地上自动长大（按真实时间，关程序也长）。
- 成年牛自动怀孕、生小牛，牧场自己壮大连片。
- 点牛挤奶、卖奶赚钱；牛也可以直接卖掉。
- 买牛奶加工器把牛奶变成奶酪，同样的奶赚更多的钱。
- 钱用来买牛仔、买高级饲料（加速长大）、扩建牧场、买更多加工器。

这个游戏的价值在于“牧场在慢慢自己变大”的轻松感，不是经营策略深度。

## 2. 用户已经定下的部分

以下内容来自用户的明确表述，不是建造者的猜测：

- 目录：`milkCow/`，一个奶牛养成小游戏，主打挂机休闲。
- 功能范围：小牛长大过程、牛繁殖过程、卖牛和牛奶赚钱、买牛奶加工器把牛奶变成奶酪赚更多钱。
- 形态：类似仓库的 `farmer` —— Windows 桌面 Tkinter 程序，偶尔瞄一眼。
- 繁殖方式：成年牛**自动怀孕**生小牛，不需要玩家配种操作。
- 牛棚容量：有上限，可以花钱扩建（用户认可“6 个位置扩到 12”这类做法，具体数值由设计定）。
- 牛要**自动活动**：在草地上走动，不像植物一样固定不动。
- 要有**买牛仔的商店**，商店还卖**高级饲料**。
- 高级饲料的作用：**长得快**（加速生长，不加产奶、不加怀孕概率）。
- 挤奶方式：**点牛挤奶才进仓库**（像 farmer 的手动收获），不会自动进仓库。

## 3. 目标

- 一块可视化的牧场，牛在上面自动走动；容量初始 4 个位置，最多扩到 12。
- 牛有三个成长阶段：牛仔 → 青年牛 → 成年牛，按真实时间生长，关程序继续长。
- 成年牛自动怀孕（约 1 小时孕期 + 半小时产后休养），条件是天棚有空位留给新生儿；生下的小牛免费获得。
- 成年牛奶房随时间蓄满（20 分钟），点击可挤奶入仓库，也可以一键挤奶。
- 仓库可卖出牛奶和奶酪换金币；牛也可以按阶段卖出。
- 商店出售：牛仔（占空位）、高级饲料（按头使用，缩短生长时间）、牛奶加工器（可买至多 3 台）、牧场扩建。
- 加工器把 3 牛奶投料、20 分钟后自动产出 1 奶酪进仓库；奶酪单价明显高于 3 瓶牛奶。
- 进度按真实时间计算：窗口关着、电脑重启都不影响；重新打开时按离线期间的时间线正确结算（怀孕、生产、长大都补齐）。
- 存档自动保存，损坏时不崩溃（完全沿用 farmer 已验证的存档安全做法）。
- 用自动化测试覆盖核心规则和存档，并做一次真实 DPI 的 GUI 冒烟测试。

## 4. 非目标

- 不做联网、好友、排行榜、账号、云同步、多存档。
- 不做疾病、死亡、饿死、心情等惩罚性养成要素。
- 不做任务、成就、天气、季节、昼夜、装饰、音效。
- 不做公牛/性别概念：所有牛都可直接怀孕（休闲设定，不做繁殖配对策略）。
- 不做奶制品以外的多级加工链（黄油、酸奶、牛奶厂等第二产线）。
- 不做手机或网页版。
- 不使用外部图片素材或第三方依赖（仅标准库 + Tkinter）。
- 不做随机产量、血统、资质等数值随机项；所有结算确定性、可测试。

## 5. 反目标

以下情况即使技术上可行，也算设计失败：

- 牛因为没挤奶、没喂食而生病、死亡或倒退。
- 需要玩家频繁点击维持进度；放着不管会亏损。
- 离线时间产生“错过的损失”（如奶溢出倒掉、牛憋坏）。
- 弹窗、系统通知、声音打扰正在工作的用户。
- 数值复杂到需要算攻略；改系统时间刷钱的明显漏洞（单机休闲可容忍一般改时间，但不留无限刷钱回路）。
- 关程序期间的事件结算与在线逐分钟玩的结果不一致（离线结算必须与在线结算一致）。

## 6. 术语与核心机制

### 6.1 成长阶段

| 阶段 | 到达条件（有效年龄） | 能做什么 |
| --- | --- | --- |
| 牛仔 | 0 ～ 45 分钟 | 只能走动；可被喂饲料；可卖 |
| 青年牛 | 45 分钟 ～ 135 分钟 | 走动；可被喂饲料；可卖 |
| 成年牛 | ≥ 135 分钟 | 挤奶、自动怀孕、可卖 |

- 有效年龄 = 出生后的真实时间 + 饲料节省的总时长（见 6.4）。
- 阶段是纯函数（由有效年龄推导），不存独立事件，离线补算天然正确。

### 6.2 挤奶

- 仅成年牛；每头牛记录 `last_milked_at`，满奶判定为 `now − max(last_milked_at, 成年时刻) ≥ 20 分钟`，牛头顶显示奶滴标记。锚定成年时刻保证初始牛与刚成年的牛首次满奶都恰好是 20 分钟。
- 点击满牛的牛 → 牛奶 +1 进仓库，重置计时；不满的牛点击只做“选中”（不出提示损失）。
- 不挤不会溢出、不会损失：奶满就挂着等，最多“白等”，没有惩罚。
- “一键挤奶”按钮把所有满奶的牛一次收完（对应 farmer 的一键收获）。
- 怀孕和产后休养的成年牛照常可挤奶（保证收入不断档）。

### 6.3 自动怀孕与生产

状态机（每头成年牛独立）：

```
空闲(可孕) --有空位时自动--> 怀孕(60分钟) --> 产下小牛 --> 产后休养(30分钟) --> 空闲(可孕)
```

- 触发条件：牛处于“空闲(可孕)”、牧场存在**预留空位**、且系统当前时间已过其可孕时刻。
- 初始牛进入游戏即满足“成年 + 空位充足”（`eligible_at =` 开局时刻），首次 `catch_up` 立即怀孕：玩家开局第一眼就能看到爱心标记，约 1 小时后迎来第一头小牛。
- 预留空位规则：`牛总数 + 已怀孕牛数 < 容量上限` 时才算有空位。这保证任何时刻不会出现“生不下”。**买牛仔同样受此闸门约束**（防止购买后孕妇生产时超员）。
- catch_up 派生时间戳一律锚定**事件自身时间**，不锚定结算探测时刻：小牛 `born_at = 预产期`、母亲休养结束 `= 预产期 + POSTPARTUM`、再孕 `due_at = 休养结束 + GESTATION`。这是“离线一跳 = 在线逐步”成立的结构性保证。
- 怀孕到预产期自动产牛：小牛作为“牛仔”入场，占一个位置，获得默认名字。
- 产下后母亲进入产后休养 30 分钟，之后回到可孕。
- 牧场满员时可孕的牛排队等待：任何腾出空位的瞬间（卖牛等）按牛进入可孕状态的先后顺序补位怀孕。
- 离线结算：怀孕、生产、休养全部由时间戳推导；`catch_up(now)` 按最早事件时间逐步推进到当前时间，**与在线挂机结果一致**（这是核心测试点）。

### 6.4 高级饲料

- 商店购买，按“份”进背包；对**未成年**的牛使用，一次消耗 1 份。
- 每喂 1 次，给该牛累加**固定 15 分钟**“成长 credit”（常量 `FEED_CREDIT = 900` 秒，非百分比），有效年龄按此提前。
- 每头牛最多喂 3 次（最多省 45 分钟）；同一头牛两次投喂间隔至少 10 分钟。
- 成年后不能再喂；不喂没有任何惩罚，只是慢。
- 机制刻意对齐 farmer 的“浇水”，用户零学习成本。

### 6.5 奶酪加工

- 加工器为商店购买的设备，最多 3 台；价格 300 / 700 / 1500 递增。
- 空闲机器点击“投料”：消耗 3 瓶牛奶，20 分钟后**自动**产出 1 块奶酪进仓库，机器随即空闲可再投。
- 产出无人值守不丢失（挂机友好）；投料需要玩家点击，是游戏里为数不多的“有事可做”。
- “全部投料”按钮把所有空闲机器用库存牛奶一次性排满。
- 奶酪本身没有二次加工，直接卖出。

### 6.6 经济

| 项 | 数值 |
| --- | --- |
| 初始金币 | 200 |
| 初始牛 | 1 头成年牛（牧场容量 4） |
| 买牛仔 | 150 |
| 卖牛价 | 牛仔 80 / 青年牛 160 / 成年牛 350 |
| 高级饲料 | 25/份 |
| 牛奶卖价 | 15/瓶 |
| 奶酪卖价 | 75/块（3 牛奶 → 1 奶酪，+30 毛利） |
| 加工器 | 第 1/2/3 台 300 / 700 / 1500 |
| 牧场扩建 | 第 5～12 位各 200/400/700/1000/1500/2200/3000/4000 |

收益模型（用于自检，不要求精确）：

- 1 头成年牛直卖牛奶：45 金币/小时。
- 繁殖：每头成年牛 ≈ 1.5 小时 1 头牛仔，受容量闸门限制，牧场自我扩张是主增长曲线。
- 成熟期（12 牛 + 3 机）：牛奶直卖 540/小时；3 台加工器满负荷 ≈ 810/小时（9 奶酪 675 + 富余 9 奶 135），约为直卖 1.5 倍——奶酪是终局放大器而非唯一玩法，投料点击次数是它的“税”。
- 卖成年牛 350 ≈ 8 小时牛奶钱，中途退出随时可变现，无沉没成本。
- 无负和回路：饲料和买牛仔都只加速产能，不存在亏本陷阱。

### 6.7 卖出是金币唯一来源

除初始 200 金币外，金币只能来自：卖牛奶、卖奶酪、卖牛。所有购买只消耗金币。与 farmer 一致。

### 7.2 牧场画布与牛的自动活动

- 草地画布约 760×460：绿色渐变草地、白色栅栏描边、少量深浅草斑（固定图案）。
- 每头牛是一个独立 Canvas 图形组：身体椭圆 + 黑斑 + 头 + 耳 + 腿，尺寸按阶段（牛仔小、成年大），孕期身体略圆。
- **自动走动**（纯 GUI 装饰，不写回核心状态）：每 300ms 一次 GUI tick，每头牛以恒速小碎步移向随机目标点，到达后随机停留 2～8 秒再选新目标；牛仔步子更快、更活泼。测试时可用固定 seed / 关闭动画（`start_loops=False` 风格参数）保证确定性。
- 牛名字在脚下小字显示（`anchor="n"`，y 留正上边距——遵守项目 DPI 经验）。
- 头顶状态标记（Canvas 绘制）：满奶 = 白色奶滴；怀孕 = 小爱心。
- 点击牛：满奶 → 直接挤奶并飘字“+1 牛奶”；不满 → 选中该牛（操作栏刷新）。
- 点击空白草地：取消选中。

### 7.3 顶栏

金币、`牛 5/6（孕2）`、可挤奶数量、累计收入、扩建按钮（显示下一位价格；满 12 后显示“已全部扩建”）。

### 7.4 右侧仓库面板

- 宽 340 像素（farmer 验证值），自然宽度布局，不用固定字符宽度。
- 两行：牛奶、奶酪，显示数量、单价、`卖出`；下方 `全部卖出（N 金币）`。空库存置灰。

### 7.5 操作栏（选中牛时出现）

- 名字、阶段、状态（可孕/怀孕剩 X 分/休养剩 X 分）、下次挤奶倒计时或“满奶”。
- 按钮：`挤奶`（满奶时高亮）、`喂食（背包 N 份）`（未成年且可喂时可用，置灰原因写进按钮文字）、`卖牛 350`。
- 未选中任何牛时，操作栏显示引导文案“点一头牛试试”。

### 7.6 商店栏（底部门户）

- `买牛仔 150`（无空位时置灰显示“牧场满了”）、`高级饲料 25`、`买加工器 <价格>`（第 3 台后置灰）。
- 加工器区：每台一行，`#1 空闲 [投料（3牛奶）]` / `#2 制作中 ▓▓▓░░ 12:04`；行尾全局 `[全部投料]`。

### 7.7 状态栏与窗口标题

- 状态栏：最近操作反馈 3 秒后回落到默认提示；金币不足、牧场满员等失败原因写这里，不弹窗。
- 标题：`奶牛牧场（3 可挤）`，每秒随可挤数量更新；没有可挤时只有`奶牛牧场`。

## 8. 存档与时间

### 8.1 存档内容

`milkCow/save.json`（与程序同目录）：

```json
{
  "version": 1,
  "coins": 320,
  "capacity": 6,
  "next_cow_id": 7,
  "cows": [
    {
      "id": 1,
      "name": "花花",
      "born_at": 1762750000.0,
      "fed_count": 2,
      "last_fed_at": 1762750600.0,
      "last_milked_at": 1762751200.0,
      "pregnant": true,
      "due_at": 1762752600.0,
      "recovery_until": 0.0
    }
  ],
  "machines": [1762751800.0, null],
  "warehouse": {"milk": 7, "cheese": 2},
  "feed_count": 2,
  "total_income": 1280,
  "total_births": 3,
  "settled_until": 1762752000.0,
  "saved_at": 1762752000.0
}
```

- `cows` 按 id 排序、id 组内唯一且都小于 `next_cow_id`（交叉校验，防手改档撞号）；阶段不存储，由 `born_at + fed_count×FEED_CREDIT` 推导。
- 繁殖状态为三个独立字段：`pregnant`（bool）+ `due_at`（预产期）+ `recovery_until`（产后休养结束时刻）。可孕时刻不单独存储，由 `max(recovery_until, 成年时刻)` 推导，补算排队顺序用。
- `machines`：长度=已购买台数（≤3），数值表示制作中的 `started_at`，`null` 表示空闲；完成时刻 = started_at + 20 分钟，读取时过期则结算进仓库。
- `version` 必须等于 1（不匹配按损坏处理，为将来 schema 演进留防线）；`settled_until` 为已结算到的时间点，保证 catch_up 幂等。
- 字段缺失或非法：整档判定损坏 → 备份为 `save.corrupt-<时间戳>.json` 并重开；`OSError`（占用/权限）不当作损坏，本次进入不写盘模式。与 farmer 完全一致。

### 8.2 保存时机

每次买卖、挤奶、喂食、投料、扩建后；每 10 秒自动保存；关闭窗口时保存。离线结算（`catch_up`）**本身不算玩家操作，但成功后会触发一次保存**——保证崩溃/断电后不会重复结算（结算幂等：再次 catch_up 到同一 now 不产生新事件）。

### 8.3 时间规则

- 全部使用 `time.time()` 时间戳；核心接口显式注入 `now`，时钟可替换以便测试。
- 允许系统时间回拨：所有推导用 `max(0, …)` 夹逼；回拨期间的事件（如已过的预产期）按回拨后的时间线重新推导，不崩溃、不产生负数库存。

```
  run_milkcow.bat      Windows 双击启动
  README.md            玩法与运行说明

```

### 9.1 核心接口（`cow_core.py`）

常量：`GROWTH_STAGES`（阈值 45/135 分钟）、`FEED_CREDIT=900` 秒（每次喂食累加 15 分钟有效年龄，3 次共 45 分钟）、`FEED_MAX=3`、`FEED_COOLDOWN=600`、`MILK_INTERVAL=1200`、`GESTATION=3600`、`POSTPARTUM=1800`、`CHEESE_MILK_COST=3`、`CHEESE_TIME=1200`、`INITIAL_COWS=1`、`CAPACITY_PRICES`、`MACHINE_PRICES`、`COW_SELL_PRICES`、`MILK_PRICE=15`、`CHEESE_PRICE=75`、`CALF_PRICE=150`、`FEED_PRICE=25`、`INITIAL_COINS=200`。

- `Cow`：id、born_at、fed_count、last_fed_at、preg_state、due_at、eligible_at、last_milked_at。
  - `stage(cow, now)`：牛仔/青年牛/成年。
  - `is_milking_ready(cow, now)`。
- `Machine`：空闲 / started_at。
- `GameState`：金币、容量、cows、machines、warehouse、feed_count、统计。
  - `catch_up(now)`：结算离线/在线到当前时刻的所有时间驱动事件（奶满不算事件——纯推导；怀孕/生产/休养是事件）。规则：循环取 `due_at ≤ now` 的最早孕妇 → 生产（小牛入场，母牛进产后休养）→ 检查可孕牛按 `eligible_at` 先进先出 + 预留空位规则 → 怀孕（`due_at = max(now_of_event, eligible_at) + GESTATION`）；机器完成 → 奶酪入仓。必须幂等且与“一直在线逐步玩”结果一致。
  - `buy_calf(now)`、`sell_cow(cow_id)`（pregnant 的牛也可卖，连同腹中牛失去，无惩罚提示一次）、`milk(cow_id, now)`、`milk_all(now)`、`feed(cow_id, now)`（校验未成年/次数/冷却/背包）、`buy_feed()`、`buy_machine()`、`process_cheese(machine_index)`、`process_all()`、`expand_capacity()`。
  - 卖牛价按卖出瞬间阶段计算；挤奶/收获本身不加金币。
- `load_state(path)` / `save_state(state, path)`：与 farmer 同样的原子写 + 三分类容错（不存在/损坏/I-O 错误）。

### 9.2 界面接口（`cow_gui.py`）

- `CowApp(tk.Tk)`：`refresh()` 每秒（状态、倒计时、标题、可挤数）；`_animate()` 每 300ms（牛的位置插值）；`start_loops=False` 供测试构建窗口而不跑循环。
- 牛的绘制参数（体型、斑纹、朝向）由 GUI 按 id 派生（`id % n`），保证同一头牛外形稳定不闪烁。
- 启动时 `SetProcessDpiAwareness(1)`（与 farmer 相同，失败忽略）。

### 9.3 DPI/布局纪律（来自项目经验，必须执行）

- 布局回归测试必须在**子进程**中先调用与 `main()` 相同的 DPI 设置再建 Tk，不允许同进程直接实例化。
- 中文标签用自然宽度 + pack/grid 权重；不做固定字符宽度。
- `pack_propagate(False)` 的面板要逐个检查子控件 `winfo_reqwidth() <= winfo_width()`。
- Canvas 文字 `anchor="n"` 且留正上边距；断言 `font.measure(text) <= width`、bbox 不出画布。

## 10. 测试策略

### 10.1 核心逻辑（`test_cow.py`，unittest，注入时钟）

1. 初始状态：200 金币、1 成年牛、容量 4、仓库空。
2. 阶段推导：0/44/45/134/135 分钟边界；喂料 credit 后边界前移，最多省 45 分钟。
3. 挤奶：20 分钟内不可挤；挤后奶 +1、计时重置；一键挤奶只收满牛；孕/休养牛可挤。
4. 怀孕：成年 + 有空位 → 自动怀孕；预产期生产、小牛入场、休养 30 分钟后再孕；`牛数+孕妇数 ≥ 容量` 时不孕；腾位后按 eligible_at 先后补位。
5. **离线一致性**：同一初始档，A) 在线每 5 分钟 catch_up 推进 6 小时；B) 直接 catch_up 跳到 6 小时——两结果（牛数/状态/仓库/金币）完全一致。多孕妇同刻生产、恰好跨成年、生产与再孕链式发生等边界。
6. 加工器：投料扣 3 奶；20 分钟后 catch_up 出 1 奶酪；3 台全投/全部投料排满；牛奶不足投料被拒。
7. 经济：买牛仔 150（满员拒绝）、卖牛价按阶段、扩建价格序列、金币不足各操作报“金币不够”。
8. 喂食：次数上限、10 分钟冷却、成年拒绝、背包不足拒绝。
9. 存档往返 + 损坏容错 + I/O 错误不覆盖原档（照抄 farmer 测试模式）。
10. catch_up 幂等：对同一 now 重复调用不改变结果。

### 10.2 GUI 冒烟（`test_gui_smoke.py`）

- 子进程真实 DPI 下构建窗口：1280×680、`minsize`、仓库面板 340、牧场画布尺寸；逐控件宽度断言；Canvas 牛名字与标记 bbox 不出界（对应 farmer 的 `test_layout_fits_with_real_dpi_awareness`）。
- 种一头满奶牛（用时钟注入），`refresh()` 后标题出现“（1 可挤）”；调挤奶处理函数后仓库牛奶 +1。
- 动画 tick 在关闭动画模式下不影响核心状态；调 `catch_up` 后 UI 数据与核心一致。
- 关闭窗口时保存文件。

### 10.3 人工验收

1. 双击 `run_milkcow.bat` 打开“奶牛牧场”，顶栏金币 200、牛 1/4，草地上有 1 头成年牛在走动。
2. 牛满奶后（初始 20 分钟）点击它 → 飘字 +1 牛奶、仓库牛奶 ×1、金币不变。
3. 约 1 小时后牛怀孕（爱心标记）、再过 1 小时生下小牛，牧场变 2 头，名字自动生成。
4. 卖出牛奶获得金币；买牛仔后牧场 +1 头小牛仔，牛仔明显比成年牛小。
5. 对牛仔点“喂食”后剩余长大时间缩短 15 分钟；同一头第 4 次被拒。
6. 买加工器 → 投料 3 牛奶 → 20 分钟后奶酪自动进仓库；卖奶酪单价 75。
7. 关掉程序 2 小时再打开：牛照常长大了、该生的生了、该做的奶酪做了，与不关程序的结果一致。
8. 牧场满员时不再生小牛仔；卖 1 头腾位后，排队的母牛补位怀孕。
9. 存档损坏（手工改坏 save.json）能正常启动并提示重开；程序运行中用记事本占用 save.json 不崩溃、不覆盖。
10. 高分屏（150% 缩放）下无文字裁切、无标签挤压；`python -m unittest test_cow test_gui_smoke -v` 全绿。

## 11. 留给建造者的细节决定

- 牛的具体配色、斑纹形状、走动速度参数；牧场画布的底色与栅栏样式。
- 小牛默认名字池（内置 12 个中文昵称循环取未占用）。
- 飘字、爱心/奶滴图标等纯装饰绘制细节。
- 数值微调（±20% 以内）允许，但必须保持 §6.6 的收益结构。

## 12. 风险与取舍

- **离线事件补算**是本作相对 farmer 的最大新风险：怀孕链、排队补位、幂等都要靠“在线逐步 = 离线一跳”的一致性测试兜底，实现时先写该测试。
- 自动走动是纯装饰：核心状态绝不依赖位置，动画不参与存档，测试可关。
- Tk 8.6 禁用 emoji，全部矢量绘制（同 farmer）。
- 孕妇可挤奶、可卖：规则简单化，牺牲一点“真实牧场”拟真换挂机轻松；卖孕妇的提示写在状态栏。
- 奶酪 1.42 倍收益差：刻意不做太高，避免“不加工就输了”的焦虑；加工是锦上添花的点击游戏。
- 改系统时间：单机休闲接受，同 farmer 不做防作弊。
