# 云岫修仙录 V2.0 开发报告

## 新增功能
- 五行灵根一次性觉醒，分别影响灵石、修为、离线、吐纳和建设成本；旧玩家保留进度补选。
- 三本功法，境界与残卷解锁、单本装备、五级养成、多资源升级。
- 三处秘境与三档时长，真实时间计时、开始时奖励快照、离线完成、一次领取。
- 三种丹药，材料原子扣除、库存、服用增益、绝对到期时间、同类刷新。
- 新任务与成就、材料库存显示、功法/秘境/丹房导航及响应式卡片。

## 修改的原有模块
GameConfig：集中新增配置；GameState：新增字段与校验；Rates：灵根/功法/丹药倍率及按到期时间分段结算；SaveSystem：迁移与离线收益；GameEngine：后台补算和增益过期；QuestSystem/AchievementSystem：新增真实指标；UI：新增面板、事件委托与反馈。继续复用 Effects 和原有修炼、建筑接口。

## 存档迁移
沿用原本地存储入口，保留境界、建筑、资源及任务进度。缺失的 cultivation、expedition、alchemy 和新增统计字段自动补默认值；非法数据经迁移校验。未觉醒旧档首次显示灵根选择。秘境保存结束时间与奖励快照；丹药保存到期时间，离线收益先分段计算再清理过期增益。待领取收益保留金额，避免按当前增益重新估价。

## 数值配置位置
单 HTML 内 GameConfig.SPIRIT_ROOTS / SPIRIT_ROOT_ORDER、TECHNIQUES / TECH_MAX_LEVEL / TECH_UPGRADE_COSTS、EXPEDITIONS / EXPEDITION_DURATIONS / EXPEDITION_REALM_SCALE、PILLS / PILL_ORDER，以及 QUESTS 和成就配置。原有资源基础公式保留，通过倍率接入新增养成。

- smoke 71、v2 数据层 79、灵根 28、功法 36、秘境 30、炼丹 38、任务成就 96，共 378 项全部通过。
- test/v2-ui.js：觉醒→功法解锁升级→秘境领取→炼丹服药集成流程通过（DOM 桩）。
- test/v2-offline.js：离线中途丹药到期，分段收益回归通过；修复前该测试失败。

- 交付副本与 index.html 内容相同，游戏无需 Node、服务器、安装或外部资源；test 目录仅用于开发验证。

### 启动交互修复
修复每 100ms 比较序列化 HTML 导致 DOM 重建、点击被打断及动画重启的问题。使用原始渲染签名保留节点；灵根改为页面内确认。新增渲染稳定性回归通过。此前关于使用原生确认框的说明已被此修复取代。


### 滚动性能优化
分离收益 tick 和自动 UI 刷新：UI_REFRESH_MS=300、SCROLL_IDLE_MS=180 集中于 GameConfig。滚动期间自动刷新延后，主动操作即时生效；降低触屏模糊和背景动画开销。新增滚动回归通过；未进行真实设备帧率测量。


### 新增趣味玩法：历练策略与机缘
在秘境面板选择稳步探索、寻药采集、访古寻卷。后两种以更长耗时换取定向材料，并在归来时出现药圃、石碑或灵兽机缘，提供保底收取与冒险选择。聚气丹增加冒险成功率；事件结果持久化，不能刷新重抽或重复领取。新增机缘成长任务。所有倍率、概率和奖励位于 GameConfig.EXPLORATION_ROUTES / EXPLORATION_EVENTS / EXPLORATION_RISK_CHANCE / EXPLORATION_PILL_CHANCE。exploration 字段对旧档补默认值。原 378 项与新增集成测试通过；本次未新增真实设备视觉验收。按用户要求，后续仅维护 index.html，不再生成 V2.0 副本。
