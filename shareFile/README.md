# 局域网文件共享（shareFile）

在同一个 Wi-Fi 或局域网里，把电脑上的文件用浏览器传给手机、平板或另一台电脑，不经过云服务，不压缩、不转码。

电脑端是一个小窗口程序：选定共享文件夹，窗口显示局域网地址、二维码和 4 位口令。手机扫码并输入口令后，就能浏览、下载和上传文件。

## 特性

- Windows / macOS / Linux 主机；iOS / Android / 其他电脑用浏览器访问，不装 App。
- 文本文件、视频文件原样传输，流式读写，内存占用不随文件大小增长。
- 下载支持 `Range`，断点续传、Safari 大文件下载更稳。
- 网页上传显示进度和速度，可取消，同时最多 3 个文件。
- 同名文件自动保存为 `name (1).ext`，绝不覆盖。
- 4 位口令保护；连续输错 5 次锁定 60 秒；网页端不能删除或重命名。
- 内置纯 Python 二维码编码器，离线可用；如果安装了 `segno` 会优先使用它。

## 运行

需要 Python 3.8 或更高版本，以及 Tkinter。

### Windows

双击 `run_share.bat`，或在当前目录运行：

```bash
python share_app.py
```

首次启动时 Windows 防火墙可能弹窗，请允许“专用网络”访问。否则手机能扫码但连不上。

### macOS / Linux

```bash
./run_share.sh
```

或：

```bash
python3 share_app.py
```

Linux 如果提示缺少 Tkinter，先安装：

```bash
sudo apt install python3-tk
```

可选依赖（不装也能用内置二维码）：

```bash
python -m pip install -r requirements.txt
```

`requirements.txt` 里只有被注释的 `segno`，装与不装都不影响运行。

## 使用

1. 电脑和手机连同一个 Wi-Fi。
2. 手机扫窗口上的二维码，或手动输入窗口里的 `http://<地址>:<端口>/`。
3. 在网页里输入窗口上显示的 4 位口令。
4. 点文件右侧的“下载”；点“上传”或把文件拖进网页即可上传。
5. 电脑窗口的“传输记录”会显示方向、文件名、进度和速度。

窗口里还可以：

- `选择…` 换共享文件夹（立即生效，不用重启；正在传的任务继续写旧目录）。
- `打开` 在文件管理器里打开共享文件夹。删除、重命名请在这里操作。
- `换一个口令` 让已登录的网页立即失效。

## 速度预期

- 千兆有线局域网通常能到约 110 MB/s，接近网线带宽。
- Wi-Fi 取决于路由器、频段和信号；5 GHz 通常明显快于 2.4 GHz，隔墙会下降。
- 程序不做压缩和加密，下载优先使用系统 `sendfile`，一般不是瓶颈。
- 手机浏览器写入存储、视频文件所在磁盘的速度也可能成为上限。

## 数据与配置

- 默认共享目录：`shareFile/shared/`；选择其他目录后写入 `shareFile/config.json`。
- 隐藏文件、`~$` 开头的 Office 临时文件、`.sharefile-tmp/` 不会出现在网页列表里。
- 上传先写入 `.sharefile-tmp/`，完成后原子移动到共享目录；中断不会留下半截文件。
- 口令每次启动随机生成；登录会话保持 12 小时。
- 网页端只提供浏览、下载、上传。删除、重命名、新建子目录请在电脑上操作。

## 限制

- 只适合可信局域网。4 位口令是轻量防护，不是公网安全方案，不要把端口映射到互联网。
- 不做 NAT 穿透、云中转、账号体系、TLS。
- 访客 Wi-Fi 若开启“客户端隔离”，设备之间无法互访，这是网络限制。
- 不做视频在线播放或转码，视频以原文件下载。
- iOS 上传很大的文件时，建议保持页面在前台、屏幕不锁定；Safari 下载会进入“文件”App。
- 网页端上传只进入共享目录根层，不支持在网页里新建子目录。

## 测试

```bash
cd shareFile
python -m unittest -v
node --check web/app.js
```

测试覆盖路径越界、文件名清洗、Range、口令限流、上传中断清理、并发同名上传、并发下载、二维码结构/纠错校验，以及一次真实窗口 + 上传的 GUI 冒烟流程。
