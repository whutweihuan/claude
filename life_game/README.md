# 康威生命游戏

用 Python + Tkinter 实现的康威生命游戏。玩家可以直接在网格上画出任意初始图形，然后观察它按规则自行演化。

## 运行

双击 `run_life.bat`，或在当前目录执行：

```bash
python life_gui.py
```

需要 Python 3.8 及以上版本。Windows 官方 Python 安装包自带 Tkinter。

## 操作

| 操作 | 说明 |
|------|------|
| 左键点击 / 拖动 | 绘制活细胞 |
| 右键点击 / 拖动 | 擦除细胞 |
| 空格 | 开始 / 暂停 |
| N | 单步演化 |
| C | 清空棋盘 |
| R | 随机生成初始图形 |
| 速度滑块 | 调节每代之间的间隔（50–1000 ms） |
| 预设图形 | 一键载入方块、闪烁灯、滑翔机、脉冲星或高斯帕滑翔机枪 |

开始演化后仍可以继续画图，画图会自动暂停。有限网格之外的邻居一律视为死亡，细胞不会从另一侧绕回来。

## 规则

每个格子根据周围 8 个邻居的状态更新：

- 活细胞有 2 或 3 个活邻居时继续存活；
- 死细胞恰好有 3 个活邻居时出生；
- 其他情况死亡或保持死亡。

## 文件

- `life.py`：与界面无关的核心逻辑和预设图形；
- `life_gui.py`：Tkinter 界面；
- `test_life.py`：核心规则与图形测试；
- `test_gui_smoke.py`：界面行为测试；
- `run_life.bat`：Windows 启动脚本。

## 测试

```bash
python -m unittest test_life test_gui_smoke -v
```
