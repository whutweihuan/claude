# 小菜园

一个挂在电脑旁边、偶尔瞄一眼的种田小游戏：种下作物后按真实时间生长，成熟后收进仓库，卖钱再买种子和地。

## 运行

双击 `run_farmer.bat`，或在当前目录运行：

```bash
python farm_gui.py
```

需要 Python 3.8+（仅使用标准库和 Tkinter）。

## 玩法

- 在底部选一种种子，再点空地种下；种植会扣金币。
- 作物按真实时间生长，关掉程序也会继续长。
- 生长中的地块可以浇水：每次缩短总时长的 10%，每次种植最多 3 次，间隔至少 10 分钟。不浇不会枯死。
- 成熟后点地块或“一键收获”，作物进入右侧仓库。
- 在仓库点“卖出”换金币，或“全部卖出”一次清空。
- 金币够时点右上角“开垦”解锁新地，最多 8 块。

| 玉米 | 4 小时 | 80 | 260 |
| 南瓜 | 8 小时 | 140 | 480 |

初始 60 金币、4 块地。第 5～8 块地开垦价：200 / 500 / 1000 / 1800。

## 存档

存档在 `farmer/save.json`，每次操作和每 10 秒自动保存；关闭窗口时也会保存。

存档损坏时会备份为 `save.corrupt-<时间戳>.json` 并重新开始。
